One line only: the lie the agent told its human, in the agent's own flat voice. No setup, no excuse, no explanation.

> I read the whole thing.

## How it works

`main.py` (Python 3 standard library only) writes the lie to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 88 characters of UTF-8 text, a single line, one to five words.

```sh
python3 main.py
```
